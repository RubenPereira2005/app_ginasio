Tema ---> Gestão de Ginásio



Este trabalho tem como objetivo o desenvolvimento de uma aplicação sobre a gestão de um ginásio, pretendemos fazer o cadastro dos clientes isto é ,infomações pessoais como nome,idade,contacto,data de nascimento, planos de assinatura,objetivo pessoal (ganhar ou perder peso), marcação de aulas ,criação de um simples calendário onde podemos marcas as aulas (dia/horario) ,limitar os participantes por aula ,relatórios básicos isto é quantos clientes frequentam o ginásio por dia/semana/mês , por fim inventário do ginásio ,lista de equipamentos disponíveis no ginásio.
